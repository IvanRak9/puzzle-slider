# GameBoard()

Компонент ігрового поля (GameBoard). Відповідає за рендеринг сітки з плитками на основі поточного стану гри. Динамічно змінює кількість колонок та рядків залежно від налаштувань.

Parameters:
Name Type Description
props.tiles Array.<(number|null)>

Масив чисел, що представляють поточний стан поля. null - це порожня клітинка.
props.onTileClick function

Функція-обробник кліку по конкретній плитці. Приймає число (number), на яке клікнули.
props.boardSize number

Розмір ігрового поля (наприклад, 3 для 3x3, 4 для 4x4).

View Source GameBoard/GameBoard.jsx, line 19

Example
// Приклад поля 2x2
const tiles = [1, 2, 3, null];
return <GameBoard tiles={tiles} boardSize={2} onTileClick={(num) => console.log(num)} />
* @param {Object} props - Властивості компонента.

# Modal()

Компонент модального вікна (Modal). Використовує React Portal для рендерингу вікна поверх усього іншого контенту в DOM. Має вбудовану анімацію появи (fade-in-up) та затемнений фон.

  • Важливо: Для правильної роботи в index.html або головному файлі має бути <div id="modal-root"></div>.
Parameters:
Name Type Description
props.isOpen boolean

Прапорець, що визначає, чи відкрите модальне вікно (true - відкрите, false - приховане).
props.children React.ReactNode

Внутрішній контент модального вікна (текст, кнопки тощо).

View Source Modal/Modal.jsx, line 22

Example
return (
<Modal isOpen={true}>
<h2 className="text-xl font-bold">Вітаю!</h2>
<p>Ви успішно зібрали пазл!</p>
</Modal>
)
* @param {Object} props - Властивості компонента.
